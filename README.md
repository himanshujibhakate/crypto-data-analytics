# Cryptocurrency Data Analysis & Excel Dashboard Project

## 📌 Project Overview

This project was completed as part of my virtual internship. The main objective was to analyze cryptocurrency market data and create interactive Excel dashboards to understand cryptocurrency prices, trading volumes, liquidity, and market trends.

The project uses cryptocurrency data containing information about 200 coins, including current prices, 24-hour trading volume, market capitalization, circulating supply, and price changes over different time periods.

## 🎯 Project Objectives

- Analyze cryptocurrency market data.
- Create interactive dashboards using Microsoft Excel.
- Compare cryptocurrency prices and market performance.
- Identify high-volume and liquid cryptocurrencies.
- Analyze price changes and investment opportunities.
- Use Excel formulas, PivotTables, charts, slicers, and VBA.

## 📊 Tasks Completed

### 1. Time-Based Visibility & Sentiment Analysis
- Identified the Top 10 cryptocurrencies based on 24-hour trading volume.
- Filtered cryptocurrency names based on specified starting letters.
- Created a time-based dashboard visible between 9 AM and 5 PM.
- Used VBA to control dashboard visibility and refresh functionality.

### 2. Crypto Coin Comparison Dashboard
- Compared two cryptocurrencies.
- Displayed symbol, price, trading volume, market capitalization, and circulating supply.
- Created KPIs to highlight differences in volume, market capitalization, and circulating supply.
- Applied input validation for cryptocurrency names.

### 3. Top 5 Crypto Liquidity Analysis
- Identified the Top 5 cryptocurrencies based on 24-hour trading volume.
- Grouped the remaining cryptocurrencies into Others.
- Created a dynamic pie chart.
- Added price-range filtering using slicers.

### 4. Price Change Comparison Analysis
- Compared current cryptocurrency prices with previous prices.
- Identified the Top 10 cryptocurrencies based on price change.
- Added price-range slicers.
- Created an interactive comparison table.

### 5. Low Budget Investment Insights
- Analyzed cryptocurrency price changes over 1 hour, 24 hours, and 7 days.
- Calculated average downfall percentages.
- Created five KPI indicators.
- Added five price-range categories using slicers.
- Identified cryptocurrencies with the lowest average downfall.

### 6. Historical Price Change Insights
- Analyzed historical price-change percentages.
- Filtered cryptocurrencies within the $0–$5 price range.
- Compared 7-day and 24-hour price changes.
- Created a chart displaying the Top 10 cryptocurrencies based on 1-hour price change.
