About the Project

Understanding cryptocurrency market data through Excel-based analysis and visualization.

The Cryptocurrency Data Analysis Project was developed as part of an internship project associated with ElevanceSkills.

The main purpose of this project is to analyze cryptocurrency market information and convert raw data into meaningful insights using Microsoft Excel.

The dataset contains approximately 200 cryptocurrency records with important information such as coin names, symbols, current prices, 24-hour trading volume, market capitalization, circulating supply and percentage changes over different time periods.

Six different analytical dashboards were developed. Each dashboard focuses on a specific requirement, including coin comparison, volume analysis, price movement, investment screening and historical price estimation.

Excel formulas, charts, PivotTables, slicers, data validation and VBA automation were used to create interactive and informative dashboards.

Project Tasks & Dashboards

Detailed overview of all six cryptocurrency analysis tasks completed in this project.

TASK 01

Time-Based Visibility & Sentiment Analysis

This dashboard identifies the top 10 cryptocurrency coins by 24-hour trading volume while applying coin-name and working-hour conditions.

  • Filters names starting with vowels or B, C and D.
  • Ranks selected coins by 24-hour volume.
  • Displays the top 10 selected results.
  • Chart visibility is restricted to 9 AM–5 PM.
  • Uses VBA for visibility and refresh control.
TASK 02

Crypto Coin Comparison Dashboard

This dashboard compares two selected cryptocurrencies using important market indicators.

  • Accepts two cryptocurrency names.
  • Displays symbol and current price.
  • Compares 24-hour trading volume.
  • Displays market capitalization and supply.
  • Calculates three difference KPIs.
  • Uses data validation for input checking.
TASK 03

Top 5 Crypto Liquidity Analysis

This dashboard analyzes the distribution of 24-hour cryptocurrency trading volume within selected price categories.

  • Creates two price categories.
  • $0–$50 and above $50.
  • Identifies the top five coins by volume.
  • Groups remaining coins as Others.
  • Uses an interactive pie chart.
TASK 04

Price Change Comparison Analysis

This dashboard compares current cryptocurrency prices with estimated previous-hour prices.

  • Uses 1-hour percentage change.
  • Calculates estimated previous-hour prices.
  • Ranks the top 10 coins by price change.
  • Includes price-range slicers.
  • Compares cryptocurrency price movements.
TASK 05

Low Budget Investment Insights

This dashboard identifies coins with the lowest average percentage change using the project's specified downfall assumptions.

  • Uses 1-hour, 24-hour and 7-day changes.
  • Calculates average downfall percentage.
  • Displays coin name, symbol and price.
  • Includes five price-range categories.
  • Displays total coins in the selected range.
TASK 06

Historical Price Change Insights

This dashboard compares estimated cryptocurrency price levels using different percentage-change periods.

  • Filters coins priced between $0 and $5.
  • Ranks the top 10 using 1-hour change.
  • Calculates estimated 7-day prices.
  • Calculates estimated 24-hour prices.
  • Compares both values through a chart.

Project Methodology

Step 4: Dashboard Development

Created charts, KPI sections, comparison tables and interactive slicers according to each task.

Step 6: Testing and Verification

Tested slicer selections, calculations, chart updates and dashboard outputs to check their functionality.
